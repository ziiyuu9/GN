# 🔊 ESP32-S3 WiFi 小喇叭 — 組裝與燒錄完整教學

手機連上同一個 WiFi → 開瀏覽器進這台的網頁 → 上傳 MP3／錄音檔 → 喇叭播放。

> **為什麼是 WiFi 不是藍牙？**
> 你手上這塊是 **ESP32-S3**，它只有 BLE（低功耗藍牙），**不支援手機藍牙音樂（A2DP）**，所以做不了一般的藍牙喇叭。
> 改用 WiFi 網頁操作可以達到一樣的效果（播你自己的音檔）。
> 哪天想要真正的「手機藍牙喇叭」，只要再買一塊 **舊版 ESP32（WROOM-32）**，其他零件原封不動沿用即可。

---

## 一、零件清單（對照你拍的照片）

| 照片 | 零件 | 角色 | 用到？ |
|---|---|---|---|
| IMG_6067 / 6068 | **MAX98357A** I2S 單聲道擴大機（4–8Ω 3W） | 數位轉類比 ＋ 功率放大（DAC＋擴大機二合一） | ✅ |
| IMG_6069 / 6070 / 6071 | **ESP32-S3**（S3-N16R8 開發板，雙 USB-C） | 主控、收音檔、跑網頁 | ✅ |
| IMG_6072 | **8Ω 1W 喇叭單體**（帶白色 JST 接頭） | 真正發聲的喇叭 | ✅ |
| IMG_6073 | **Arduino UNO** | — | ❌ 這套用不到，可收起來 |

**另外要自備：**
- 杜邦線或細電線（公對母／單芯線皆可），5 條以上
- 烙鐵、焊錫（MAX98357A 跟 ESP32 的排針要焊上去才好接）
- USB-C 傳輸線（要能傳資料，不是只能充電的那種）

## 二、訊號是怎麼一路走到喇叭的

```
手機            ESP32-S3              MAX98357A            8Ω 喇叭
(音樂來源) ─WiFi─▶ (收檔+解碼) ─I2S 3 條線─▶ (DAC+擴大機) ─喇叭線─▶ (發聲)
```

MAX98357A 一顆就同時做了「數位音訊轉類比」＋「放大到能推喇叭」，所以中間不需要其他零件。

---

## 三、接線表（最重要，照這個接）

MAX98357A 板上腳位（IMG_6068 正面可看到絲印）：`LRC｜BCLK｜DIN｜GAIN｜SD｜GND｜Vin`，
另一側兩個大孔是喇叭輸出 `－`（⊖）和 `＋`（⊕）。

### MAX98357A → ESP32-S3

| MAX98357A 腳 | 接到 ESP32-S3 的 | 說明 |
|---|---|---|
| **Vin** | **5V**（板上標 5V 或 VIN 的腳） | 供電，**一定要 5V，不要接 3.3V**（接 3.3V 會很小聲） |
| **GND** | **GND** | 共地，必接 |
| **BCLK** | **GPIO 5** | 位元時脈 |
| **LRC** | **GPIO 6** | 聲道選擇（word select） |
| **DIN** | **GPIO 7** | 音訊資料 |
| **GAIN** | 不接（懸空） | 預設 9dB 增益，夠用 |
| **SD** | 不接（懸空） | 懸空＝啟用喇叭 |

### MAX98357A → 喇叭

| MAX98357A 腳 | 接到喇叭 |
|---|---|
| **＋**（⊕） | 喇叭**紅**線 |
| **－**（⊖） | 喇叭**黑**線 |

> 喇叭那顆白色 JST 接頭可以：①直接剪掉、把紅黑線焊到 MAX98357A 的 ＋／－；或②焊一個對應的 JST 母座上去再插。
> 1W 喇叭配 3W 擴大機沒問題，音量別開到最大即可。

### 接線示意圖

```
   ESP32-S3                         MAX98357A                 喇叭
 ┌──────────┐                     ┌───────────┐
 │      5V  ├─────────────────────┤ Vin       │
 │      GND ├─────────────────────┤ GND       │
 │   GPIO 5 ├─────────────────────┤ BCLK      │
 │   GPIO 6 ├─────────────────────┤ LRC       │
 │   GPIO 7 ├─────────────────────┤ DIN       │
 │          │                     │ GAIN  (空)│
 │          │                     │ SD    (空)│
 │          │                     │        ＋ ├──── 紅 ──┐
 │          │                     │        － ├──── 黑 ──┤  🔊
 └──────────┘                     └───────────┘         └─ 8Ω 1W
```

> **ESP32-S3 上的 GPIO 5/6/7 在哪？** 板子兩側排針的絲印有數字（IMG_6070 / 6071 看得到 `5 6 7` 字樣）。
> 找到印著 5、6、7 的那三個孔，以及任一個 `5V`（或 `VIN`）和 `GND` 即可。

## 四、組裝步驟

1. **焊排針**：把 MAX98357A 和 ESP32-S3 的排針焊上（若還沒焊）。排針從板子背面插入、正面焊接，焊點要飽滿不要短路。
2. **接 5 條訊號線**：照上面接線表，把 Vin、GND、BCLK、LRC、DIN 五條接好。建議用不同顏色區分，GND 用黑色。
3. **接喇叭**：MAX98357A 的 ＋／－ 接喇叭紅／黑線。
4. **再檢查一次**：特別確認 **Vin 接的是 5V 不是 3.3V**、**GND 有共地**、沒有兩腳互相短路。
5. 先別急著裝進外殼，等下面燒錄＋測試會出聲了再收。

---

## 五、電腦端：Arduino IDE 設定

### 5-1 安裝 Arduino IDE 與 ESP32 支援
1. 下載安裝 [Arduino IDE](https://www.arduino.cc/en/software)（2.x 版）。
2. 開 IDE → 左側 **Boards Manager**（開發板管理員）→ 搜尋 `esp32` → 安裝 **esp32 by Espressif Systems**。

### 5-2 安裝兩個函式庫
左側 **Library Manager**（函式庫管理員）搜尋並安裝：
- **ESP32-audioI2S**（作者 *schreibfaul1*）← 負責 MP3 解碼 + I2S 輸出
- **WiFiManager**（作者 *tzapu*）← 開機跳 WiFi 設定頁

### 5-3 開發板設定（Tools / 工具 選單）
把這支程式 `esp32_wifi_speaker/esp32_wifi_speaker.ino` 用 Arduino IDE 打開，然後在 Tools 選單設定：

| 項目 | 選擇 |
|---|---|
| Board | **ESP32S3 Dev Module** |
| USB CDC On Boot | **Enabled** |
| Flash Size | **16MB (128Mb)** |
| PSRAM | **OPI PSRAM** |
| Partition Scheme | 選**有檔案系統空間**的，例如 `16M Flash (3MB APP/9.9MB FATFS)` |
| Port | 插上板子後出現的那個序列埠 |

> Partition Scheme 一定要選有 FS（檔案系統）空間的，否則音檔沒地方存。

## 六、燒錄程式

1. 用 USB-C 線把 ESP32-S3 接上電腦。**這塊有兩個 USB-C，先試靠近 RST/BOOT 按鍵那個**（IMG_6070 上方那顆）；若電腦認不到再換另一個孔。
2. Tools → Port 選到出現的序列埠。
3. 按左上角 **➡ Upload（上傳）**。
4. 若卡在 `Connecting...`：**按住板子的 BOOT 鍵不放，再按一下 RST，放開 RST，再放開 BOOT**，讓它進燒錄模式，然後重按 Upload。
5. 看到 `Done uploading` 就成功了。

## 七、第一次使用

### 7-1 設定 WiFi（只要做一次）
1. 燒錄完板子會自己開一個熱點 **`ESP32-Speaker`**。
2. 拿手機去**連這個熱點**，通常會自動跳出設定頁（沒跳的話開瀏覽器進 `192.168.4.1`）。
3. 在設定頁選**你家的 WiFi**、輸入密碼、儲存。板子會重開並連上你家 WiFi。

### 7-2 找到板子的 IP
- 在 Arduino IDE 開 **Serial Monitor（序列埠監控視窗）**，鮑率設 **115200**。
- 會印出一行 `已連上 WiFi，IP 位址：192.168.x.x` ← 記下這個 IP。

### 7-3 播放音樂
1. 手機**連上同一個 WiFi**（跟板子同一個網路）。
2. 手機瀏覽器輸入剛剛那個 IP（例：`192.168.1.50`）。
3. 網頁上：**上傳 MP3／WAV** → 在清單按 **▶ 播放** → 喇叭出聲。
4. 音量 ＋／－、刪檔、重設 WiFi 都在同一頁。

## 八、沒聲音？照這個順序查

| 症狀 | 檢查 |
|---|---|
| 完全沒聲音 | ① GND 有沒有跟 ESP32 共地 ② BCLK/LRC/DIN 是不是接到 5/6/7 ③ 喇叭 ＋－ 有沒有接好 |
| 聲音超小聲 | **Vin 八成接到 3.3V 了，改接 5V** |
| 破音、雜訊 | 音量調低（網頁 －）；線太長或沒焊牢也會雜訊 |
| 網頁打不開 | 手機跟板子要在**同一個 WiFi**；IP 有沒有打對 |
| 燒錄連不上 | 按 BOOT＋RST 進燒錄模式（見第六步第 4 點）；換另一個 USB-C 孔；換一條能傳資料的線 |
| 一直跳 WiFi 設定頁 | 密碼打錯，重連 `ESP32-Speaker` 熱點重設一次 |
